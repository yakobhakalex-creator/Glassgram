# Glassgram roadmap

This is a proposed roadmap, not a promise of release dates or feature availability. Priorities may change after testing and community feedback.

## V0.7 — Telegram compatibility

- [ ] Improve bot messages and interactive keyboards.
- [ ] Test polls, forum topics, channel discussions and group administration in authorized test chats.
- [ ] Improve media, search and error handling.
- [ ] Evaluate remaining Telegram features and API constraints.

## V0.8 — Local AI experience

- [ ] Improve Ollama model selection and connection diagnostics.
- [ ] Improve the assistant interface, cancellation and resource usage.
- [ ] Make AI data handling and provider choice explicit to the user.
- [ ] Evaluate practical models for consumer hardware.

## V0.9 — Quality and release readiness

- [ ] Improve accessibility, keyboard navigation and high-DPI behavior.
- [ ] Expand TDLib request serialization regression tests and integration tests.
- [ ] Profile memory use, scrolling and media caching.
- [ ] Improve build documentation and clean release packaging.
- [ ] Audit session handling, dependency licenses and privacy-sensitive paths.

## V1.0 — Stable release goal

- [ ] Define and test a supported feature set.
- [ ] Resolve release-blocking bugs and security issues.
- [ ] Provide installation, troubleshooting and contribution documentation.
- [ ] Publish reproducible source references and compliant binary packages.
