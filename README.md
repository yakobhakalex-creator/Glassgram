# Glassgram 0.2

Проект открывается через `Glassgram.slnx` в Visual Studio. Для сборки можно запустить `Build.cmd`, для запуска собранной версии — `Start.cmd`.

Исходники находятся в `src/Glassgram`. Код авторизации и защищённого хранилища находится в `src/Glassgram/Telegram`. Архив предыдущего проекта V9 сохранён в `reference` только как справочный материал.

Для входа в Telegram укажи собственные API ID и API hash из [my.telegram.org](https://my.telegram.org). Затем можно войти по номеру телефона или QR-коду. Приложение обрабатывает код подтверждения, при необходимости код электронной почты и облачный пароль. После первого входа TDLib восстанавливает сессию при следующем запуске. Кнопка выхода находится в настройках.

TDLib сохраняет базу в `%LOCALAPPDATA%\Glassgram\Telegram`. Случайный ключ её шифрования и API-параметры защищены Windows DPAPI для текущего пользователя. Телефонный код и облачный пароль не записываются в файлы приложения. Настройки Ollama и история диалога работают как в версии 0.1.

Сборка использует нативную TDLib 1.8.67 из пакета `tdlib.native.win-x64`, который упаковывает код [официального репозитория TDLib](https://github.com/tdlib/td). Для создания QR-изображения используется QRCoder.

Проверены сборка WinUI 3 без ошибок и предупреждений, загрузка `tdjson.dll`, переход к QR-коду и состояние «Telegram подключён» после повторного запуска приложения. Кнопка выхода доступна в настройках. Вход по телефону, коды, облачный пароль и выход реализованы, но эти ветки ещё не проверялись с реальным аккаунтом. Чаты и сообщения в версии 0.2 ещё не отображаются.
