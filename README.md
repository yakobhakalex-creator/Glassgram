# Glassgram V0.3

Открой `Glassgram.slnx` в Visual Studio. Для сборки запусти `Build.cmd`, для запуска — `Start.cmd`. Исходники приложения находятся в `src/Glassgram`, а архив исходного проекта V9 — в `reference`.

## Telegram

После входа через TDLib приложение показывает личные чаты, группы, каналы, архив и «Избранное». В списке видны аватар, имя, последнее сообщение, время и число непрочитанных сообщений. Есть поиск и изменение ширины панели чатов перетаскиванием её правого края.

История загружается порциями до 500 сообщений на чат и пополняется при прокрутке вверх. Включены отправка и получение текста, отметки прочтения, ответы с цитатой, редактирование и удаление, разделители дат, статус собеседника и индикатор набора. Список сообщений использует виртуализирующую панель. Положение прокрутки сохраняется для открытых чатов, пока их история находится в памяти. Системные уведомления Windows открывают нужный чат при нажатии, если их регистрация разрешена системой.

Светлая и тёмная темы выбираются в настройках. Интерфейс WinUI 3 с Acrylic и локальная интеграция Ollama сохранены. Автоматические ответы ИИ не включены.

## Данные и сборка

Для входа нужны собственные API ID и API hash с [my.telegram.org](https://my.telegram.org). Сессия TDLib хранится в `%LOCALAPPDATA%\Glassgram\Telegram`; ключ базы и API-параметры защищены Windows DPAPI для текущего пользователя. Код подтверждения и облачный пароль не сохраняются. Личные данные и сессия не входят в Git.

Приложение использует TDLib 1.8.67 через пакет `tdlib.native.win-x64`, собранный из [официального проекта TDLib](https://github.com/tdlib/td). Медиа и файлы в интерфейсе переписки пока представлены текстовыми подписями; их просмотр и отправка запланированы на V0.4.
