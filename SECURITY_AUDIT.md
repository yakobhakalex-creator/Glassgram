# Аудит репозитория перед публикацией

Дата проверки — 25 ноября 2026 года. Публикация в рамках этой проверки не выполнялась.

## Проверенный охват

- рабочее дерево и все 32 достижимых Git-коммита;
- имена всех файлов во всей истории;
- 6 недостижимых Git-объектов;
- URL Git remote на встроенные учётные данные;
- шаблоны Telegram bot token, OpenAI key, GitHub token, AWS access key, private key и присвоенный Telegram API hash;
- пути и имена TDLib-сессий, Telegram database, MessageCache, `.env`, локальных настроек, ключей и SQLite/DB-файлов;
- локальные пользовательские пути и похожие на телефонные номера значения.

## Результат

- Секреты, токены, приватные ключи и присвоенный Telegram API hash не обнаружены.
- Данные TDLib-сессий, Telegram database, кэш переписок и локальные настройки в истории Git не обнаружены.
- URL remote со встроенными логином или токеном не обнаружен.
- Единственное срабатывание проверки персональных данных относится к датам в `CHANGELOG.md` и является ложным.
- Git содержит одну пару имени и email автора коммитов в стандартных метаданных commit. Перед публичным размещением владелец репозитория должен убедиться, что публикация этой Git-идентичности допустима.
- `src/Glassgram/Telegram/SessionStorage.cs` является исходным кодом механизма защищённого хранения. Файлов пользовательских сессий в Git нет.

Специализированный сканер Gitleaks в системе отсутствует. Проверка выполнена локальным сканированием содержимого всех Git-ревизий и недостижимых объектов по перечисленным сигнатурам. Перед первой публикацией следует повторить проверку актуальной версией Gitleaks или эквивалентным сканером.

## Повторная проверка перед публикацией

1. Убедиться, что `git status --short` не показывает неожиданных файлов.
2. Проверить, что `.gitignore` исключает `bin`, `obj`, `.vs`, `.env`, `release`, `*.session` и `*.sqlite3`.
3. Просканировать все Git refs и недостижимые объекты сканером секретов.
4. Проверить Git-имя и email автора будущих публичных коммитов.
5. Собирать публичный архив из `git archive`, а не из рабочей папки с `%LOCALAPPDATA%` и TDLib-кэшем.
