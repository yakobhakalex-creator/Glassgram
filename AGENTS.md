# Glassgram agent rules

- После каждого успешно проверенного обновления выполнить Release self-contained publish в `C:\Glassgram\release`.
- После публикации проверить запуск через `Glassgram.exe` на рабочем столе и убедиться, что запускается актуальная Release-сборка.
- Не копировать основной `Glassgram.exe` отдельно от его зависимостей; desktop-файл является только постоянным лаунчером.
